# Новое меню (часть A, Mac) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Меню Mac-версии как в спеке: Главная; Очистка; Система (Процессы, Автозагрузка, Программы, Диски); Защита (Безопасность, Сеть); внизу Профиль и ⚙ Настройки — с полосой вкладок над страницей и нижней строкой с версией и состоянием обновлений.

**Architecture:** На Mac три нынешние страницы держат по две вкладки внутри себя (`TabControl`): «Очистка и диски», «Процессы и автозагрузка», а сеть — группа проверок «Безопасности и сети». Они разносятся на отдельные `PageViewModel`: `DiskViewModel` (из Очистки), `StartupViewModel` (из Процессов), вторая часть `SecurityViewModel` (`SecurityPart.Network`). Над страницами — свои `SectionViewModel` и `ShellMenu` (проще Windows: на Mac нет простого режима), два списка в боковой панели и полоса вкладок. Навигация по ключу страницы; ссылки Главной переводятся на новые ключи (`Disk`, `Startup`, `Network`).

**Tech Stack:** C# / Avalonia 12.1.4, .NET 10 (`net10.0`), xUnit + Avalonia.Headless. Тесты запускаются на этом Windows-ПК; настоящее поведение macOS — CI (macos-14, macos-latest, macos-15-intel) и владелец на своём Mac.

- [ ] **Step 5: `UpdateFooter`**

Create `src/PcCleaner.Mac/Core/Updates/UpdateFooter.cs` (тот же код, что в Windows-версии `src/PcCleaner/Core/Updates/UpdateFooter.cs`, но тексты по-русски без `T`):

```csharp
namespace PcCleaner.Core.Updates;

/// <summary>The corner of the window's bottom line: the version and what the updater knows (pure, unit-tested).</summary>
public static class UpdateFooter
{
    public static string Text(UpdateState state, UpdateManifest? manifest, Version current)
    {
        var version = "v" + UpdateManifest.Normalize(current).ToString(3);
        var found = manifest is null ? null : UpdateManifest.Normalize(manifest.Version).ToString(3);
        var tail = state switch
        {
            UpdateState.Checking => "проверка…",
            UpdateState.UpToDate => "последняя версия",
            UpdateState.Downloading when found is not null => $"скачивается {found}",
            UpdateState.Ready when found is not null => $"скачана {found}",
            UpdateState.ManualRequired when found is not null => $"есть версия {found}",
            UpdateState.Updated => "обновлена",
            _ => null,
        };
        return tail is null ? version : version + " · " + tail;
    }
}
```

Если у Mac-копии `UpdateManifest` нет `Normalize` — использовать `new Version(v.Major, v.Minor, Math.Max(v.Build, 0))` в локальной функции.

namespace PcCleaner.Shell;

/// <summary>The sidebar of the Mac app (spec 2026-10-27, part A): which pages are the tabs of which section.</summary>
public static class ShellMenu
{
    private sealed record Entry(string Key, string? Title, string? Icon, string[] PageKeys, SectionPlace Place);

    private static readonly Entry[] Entries =
    {
        new("Dashboard", null, null, new[] { "Dashboard" }, SectionPlace.Top),
        new("Cleaner", null, null, new[] { "Cleaner" }, SectionPlace.Top),
        new("System", "Система", "Pulse", new[] { "Processes", "Startup", "Programs", "Disk" }, SectionPlace.Top),
        new("Protection", "Защита", "Shield", new[] { "Security", "Network" }, SectionPlace.Top),
        new("Profile", null, null, new[] { "Profile" }, SectionPlace.Bottom),
        new("Settings", null, null, new[] { "Settings" }, SectionPlace.Bottom),
    };

    /// <summary>
    /// The sections over <paramref name="pages"/>, in menu order. A section gets the pages it names that exist and is left out when
    /// there are none; a page no section names gets a section of its own at the end of the main list.
    /// </summary>
    public static List<SectionViewModel> Build(IReadOnlyList<PageViewModel> pages)
    {
        PageViewModel? Find(string key) => pages.FirstOrDefault(p => string.Equals(p.Key, key, StringComparison.OrdinalIgnoreCase));

        var sections = new List<SectionViewModel>();
        foreach (var entry in Entries)
        {
            var tabs = entry.PageKeys.Select(Find).OfType<PageViewModel>().ToList();
            if (tabs.Count > 0)
                sections.Add(new SectionViewModel(entry.Key, entry.Title, entry.Icon, tabs, entry.Place));
        }
        var placed = sections.SelectMany(s => s.Tabs).ToHashSet();
        var firstBottom = sections.FindIndex(s => s.Place == SectionPlace.Bottom);
        var at = firstBottom < 0 ? sections.Count : firstBottom;
        foreach (var page in pages.Where(p => !placed.Contains(p)))
            sections.Insert(at++, new SectionViewModel(page.Key, null, null, new[] { page }, SectionPlace.Top));
        return sections;
    }
}
