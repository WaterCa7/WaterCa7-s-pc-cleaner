# Кнопки «Исправить» на Главной и действия с несколькими пунктами

Дата: 2026-10-18. Статус: одобрено пользователем, ждёт плана реализации.

## Цель

Пользователь хочет простоты: на Главной после проверки у большинства советов есть кнопка, которая решает проблему,
а в Процессах, Автозагрузке и Программах можно отметить несколько пунктов и выполнить действие одной кнопкой.

Не входит: кнопка «Отменить последнее действие», массовый карантин процессов, исправления, для которых в программе
ещё нет кода (смена DNS-серверов, правила брандмауэра, исключения антивируса, файл подкачки).

## Решения пользователя

- План для Главной (новые «Исправить», «Открыть настройки», «Исправить всё» без удаления программ) — одобрен.
- Выбор галочками на трёх страницах — одобрен.
- Несколько программ удаляются **тихо, где программа это умеет**, остальные — обычным деинсталлятором по очереди.

## Часть 1. Главная

### Модель (`Core/Health.cs`, `HealthIssue`)

Новые свойства:

| Свойство | Что даёт |
|---|---|
| `FixLabel` (по умолчанию «Исправить») | текст кнопки: «Перезагрузить», «Удалить программу», «Открыть очистку диска» |
| `InFixAll` (по умолчанию `true`) | попадает ли исправление в «Исправить всё» |
| `SettingsUri` | ссылка `ms-settings:` / `windowsdefender:`; если задана — кнопка «Открыть настройки» |

`FixAsync`, `AutoFixSafe`, `TargetPageKey` остаются. Бейдж «Безопасно исправить» по-прежнему показывается по
`AutoFixSafe`. Текст результата по-прежнему проверяет `HealthScoring.LooksLikeFailure`, поэтому новые исправления
пишут неудачи словами «Не удалось…», «Нужны права администратора…».

Каждое новое исправление перед изменением заново проверяет систему (как `FixBrokenAsync`, `DisableProxyAsync(expected)`):
данные анализа могли устареть.

### Новые кнопки «Исправить» (существующие методы сервисов)

| Модуль | Совет | Действие | В «Исправить всё» |
|---|---|---|---|
| Очистка | «Ещё N системного мусора» | `CleanAsync` системных категорий; без прав администратора — сообщение «Нужны права администратора» (Главная покажет перезапуск) | да |
| Автозагрузка | «Подозрительная запись…» | `SetEnabledAsync(item, false)`, для RunOnce — `DeleteAsync` | да |
| Программы | «Нежелательная программа…» (`FixLabel` «Удалить программу») | тихое удаление, если возможно, иначе обычное (`RunUninstallerAsync`) | нет |
| Программы | «N предустановленных приложений можно удалить» (`FixLabel` «Удалить лишние») | `RemoveStoreAppAsync` для каждого, как «Удалить лишние» на странице | нет |
| Диски | «Старые установщики и архивы в «Загрузках»» | `RecycleFiles` — в Корзину | да |
| Диски | «Осталась папка Windows.old» (`FixLabel` «Открыть очистку диска») | открыть мастер «Очистка диска» | нет |
| Безопасность | «Файл hosts подменяет адреса сайтов» | `RemoveHostsLinesAsync` опасных строк (с копией) | да |
| Безопасность | «Подменён запуск при входе в Windows» | точка восстановления + `RestoreWinlogonAsync` | да |
| Безопасность | «Перехвачен запуск системных программ» (только критичный) | точка восстановления + `RemoveIfeoDebuggerAsync` для каждой записи | да |
| Безопасность | прокси | `DisableProxyAsync(expected)` | да |
| Сеть | «DNS не отвечает» | `FlushDnsAsync` | да |
| Ускорение | «Windows ждёт перезагрузки», «Компьютер не перезагружался N дней» (`FixLabel` «Перезагрузить») | новый метод: подтверждение «сохраните работу» и перезагрузка | нет |
| Ускорение | планирование GPU без прав администратора | кнопка есть всегда; без прав — сообщение о правах (как у TRIM и брандмауэра) | да |

### «Открыть настройки» (`SettingsUri`)

- Ускорение: передавать уже существующий `SettingsUri` рекомендаций (сейчас теряется в `OptimizerService`); частота
  монитора — `ms-settings:display-advanced`; режим максимальной производительности — `ms-settings:powersleep`.
- Безопасность: антивирус выключен — `windowsdefender:`; обновления Windows — `ms-settings:windowsupdate`;
  SmartScreen — `windowsdefender://appbrowser`; удалённый рабочий стол — `ms-settings:remotedesktop`;
  шифрование — `ms-settings:deviceencryption`; целостность памяти — `windowsdefender://coreisolation`;
  широкие исключения — `windowsdefender://threatsettings`.
- Сеть: нет доступа в интернет — `ms-settings:network-status`.

Открытие — через `ProcessRunner`/`UseShellExecute`; ошибка открытия показывается как обычная ошибка.

### «Исправить всё (N)»

Заменяет «Исправить безопасное». Берёт все советы с `CanFix && InFixAll`. Одно подтверждение со списком, точка
восстановления, исправления по одному с прогрессом и отменой, итоговое окно (код `FixSafeAsync` остаётся, меняется отбор).
Не входят: удаление программ и приложений, открытие мастеров, перезагрузка. Если часть исправлений вернула «Нужны права
администратора», итог предлагает перезапуск от имени администратора.

### Без кнопки

BIOS (XMP, частота памяти, Secure Boot, TPM, виртуализация), покупка памяти или SSD, охлаждение, резервная копия
диска, кабель монитора, сигнал Wi-Fi, «Много программ в автозагрузке», «Мало оперативной памяти», процессы
(подозрительный, нагрузка, память) — остаётся «Подробнее» с переходом на страницу.

## Часть 2. Выбор нескольких пунктов

### Общее

- Колонка галочек слева в `DataGrid`, в шапке — галочка «все видимые» (три состояния; учитывает поиск и фильтры).
- Отметки хранятся по стабильному ключу и переживают обновление списка: общий класс `CheckedSet<TKey>` в `Core`
  (отметить, снять, снять всё, «все видимые», убрать исчезнувшие ключи, счётчик). Строки берут `IsChecked` из него.
- Полоса над списком, пока отмечен хоть один пункт: «Отмечено: N · [действия] · [Снять отметки]» — общий
  `UserControl` `BulkActionBar` со слотом для кнопок.
- Защищённые пункты отметить нельзя: `CanCheck = false`, подсказка с причиной.
- Одно подтверждение со списком (первые 14, «и ещё N»; помощник `BulletList` переносится из `SettingsViewModel` в `Core`),
  затем итог «Готово: N, не удалось: M» с причинами. У каждой страницы тестовая замена `Confirm`, как в `CleanerViewModel`.
- Клик по строке, как и сейчас, открывает подробности справа; одиночные действия остаются.

### Процессы

- Ключ: `ProcessKey` строки или ключ группы. Отметка группы = все её процессы.
- `CanCheck` = `CanKill` (защищённые процессы, PID 0/4, сама программа — нельзя).
- «Завершить отмеченные»: собрать `KillTarget` всех отмеченных (уникально), `ProcessesService.Kill(targets)`,
  итог через `BuildKillReport`; предупреждение про `explorer.exe` в подтверждении; если что-то не завершилось из-за
  прав — предложить перезапуск от имени администратора. Завершённые процессы исчезают из отметок при обновлении.

### Автозагрузка

- Ключ: `StartupItem.Id`. `CanCheck` = `CanToggle || CanDelete`.
- Кнопки: «Отключить», «Включить», «Удалить». Пункты, к которым действие неприменимо (служба при удалении, уже
  отключённая запись при «Отключить»), пропускаются и называются в итоге.
- Перед действием: если среди отмеченных есть записи, требующие прав администратора, а прав нет — предложить
  перезапуск; при отказе такие записи пропускаются. Перед изменением служб — одна точка восстановления.
- Отключение/включение — `SetEnabledAsync` по очереди; удаление — существующий `DeleteManyAsync`. Итог в баннер
  страницы и одно окно.

### Программы

- Вкладка «Программы»: ключ `RegistryKeyPath`; среды выполнения (`IsRuntime`) отметить нельзя.
  «Удалить отмеченные»: подтверждение, одна точка восстановления, затем по одной: тихо, если `BuildQuietLaunch`
  даёт команду, иначе обычный деинсталлятор (`RunUninstallerAsync`), ждать завершения каждой. Отмена — после текущей
  программы. Итог по `UninstallOutcome`, затем пересканирование.
- Вкладка «Приложения Microsoft Store»: ключ `PackageFullName`; защищённые (`CanRemove = false`) отметить нельзя.
  «Удалить отмеченные»: `RemoveStoreAppAsync` по очереди, как `RemoveAllBloatAsync`.

## Проверка

- Модульные тесты на каждое новое исправление в существующих песочницах (Startup, Security, Disk, Programs, Network);
  тесты, которые сейчас утверждают `FixAsync == null` для этих советов, меняются на новое поведение.
- Тесты `HealthIssue`/Главной: отбор «Исправить всё» по `InFixAll`, кнопка «Открыть настройки», `FixLabel`.
- `CheckedSet<TKey>`: отметки переживают пересборку списка, «все видимые», удаление исчезнувших.
- Тесты моделей представления трёх страниц: отказ в подтверждении ничего не меняет, защищённые пункты не отмечаются,
  массовое действие вызывает сервис для всех отмеченных.
- Полный `dotnet test`, скриншоты страниц в режиме `--screenshots` (только чтение).
