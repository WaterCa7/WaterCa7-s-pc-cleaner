# Pro-версия: аккаунты, лицензии, установщик, новое меню, сервер и сайт

Дата: 2026-10-23. Статус: общие решения приняты пользователем. Это общая спецификация: каждый этап из раздела 9
получает свою подробную спецификацию и свой план работ. Исходный план пользователя — «план расширения.docx».

## 1. Модель продукта

- **Без входа работает бесплатная часть.** Аккаунт нужен только для Pro (покупка, привязка ПК, синхронизация).
- **Код новых версий закрывается.** Репозитории Windows- и Mac-версии становятся приватными (уже выпущенные версии
  остаются под MIT). Скачивание и автообновление переезжают на наш сервер и в отдельный публичный репозиторий только
  с релизами. Сейчас `update.json` читается из открытых релизов GitHub — без переезда обновление сломается.
- Защита лицензии не идеальна (.NET легко декомпилируется). Цель — чтобы заплатить было проще, чем искать взлом.
- Принципы из `docs/COMPETITORS.md` («Бесплатно и открыто», «Работает без интернета») меняются: бесплатная часть
  по-прежнему работает без интернета и без аккаунта; Pro проверяет лицензию через сервер (раздел 4).

## 2. Бесплатно и Pro

Два правила для любого деления:

1. **Что бесплатная версия нашла, то она и исправляет.** Pro-проверки в бесплатной версии не запускаются; вместо них —
   нейтральная строка «ещё N проверок в Pro». Никакого «нашли угрозу — заплатите за удаление»: за это Защитник и другие
   антивирусы помечают программы-ускорители как нежелательные.
2. **Инструменты отката бесплатны всегда:** журнал, карантин, резервные копии реестра, точки восстановления.

| Раздел | Бесплатно | Pro |
|---|---|---|
| Главная | Оценка 0–100, быстрая проверка, живые показатели, исправление найденного | Полная проверка (все глубокие проверки), проверка по расписанию |
| Очистка | Временные файлы Windows, корзина, кэш браузеров | Кэш шейдеров, Discord, Steam, кэш обновлений, отчёты об ошибках, дампы, DISM, очистка по расписанию |
| Процессы | Список, нагрузка, завершение | Проверка подписи, подделки, майнеры, удалённый доступ, VirusTotal, карантин |
| Автозагрузка | Реестр и папки автозагрузки, отключение | Планировщик, службы, «битые» записи |
| Программы | Список и удаление | Нежелательный софт, предустановленный мусор, приложения Store, обновление программ |
| Диски | Свободное место, здоровье дисков | Что занимает место, большие файлы, старые установщики, дубликаты, TRIM и оптимизация |
| Комплектующие *(новый)* | Характеристики ПК и текущее состояние | История износа и температур, тревоги |
| Ускорение | — | Весь раздел |
| Сеть | — | Весь раздел и «кто подключён к Wi-Fi» |
| Безопасность | Антивирус, брандмауэр, UAC, обновления Windows | hosts, IFEO/Winlogon, прокси, DNS, расширения браузеров, утечки паролей, модуль приватности |
| Проверка файлов *(новый)* | Перетащить или выбрать файл, проверка Защитником | VirusTotal, наблюдение за «Загрузками» |
| Телефон | Приложения, место, память, состояние | Резервные копии, выгрузка сообщений |
| Аккаунт | — | Несколько ПК, синхронизация настроек, приоритетная поддержка |

- Характеристики ПК переезжают из «Ускорения» в «Комплектующие».
- Простой и экспертный режимы **не связаны с лицензией**.
- Бесплатный API VirusTotal по его правилам нельзя использовать в коммерческом продукте. Для Pro нужен разрешённый
  источник (платный API или другой сервис) — решается в спецификации этапа 5. Если подходящего нет, Pro-проверка
  файлов обходится Защитником и наблюдением за «Загрузками».
- Нынешним пользователям можно дать Pro бесплатно на 3–6 месяцев (решение — к этапу 4).

## 3. Тарифы и цены

- **Pro** — 1 компьютер, **Pro Семья** — 3 компьютера (примерно в 1,5 раза дороже). Каждый — на месяц, на год
  (скидка около 40 %) или навсегда (примерно как 2–3 года подписки).
- Цены хранятся на сервере и меняются в панели админа без выпуска программы.
- **Пробного периода нет.** Вместо него — скидка на первый месяц новым пользователям и по реферальной ссылке.
  Скидка привязана к «номеру компьютера»: если этот ПК уже был в любом аккаунте, второй раз скидки нет. Награда
  пригласившему начисляется только после оплаты приглашённого.
- Устройство — это Windows-ПК или Mac (одна лицензия на обе системы; вход появится и в Mac-версии). Телефон не считается.
- Замена ПК: отвязать в «Профиле» или в кабинете на сайте, не чаще раза в неделю.
- «Номер компьютера» — хэш от железа (не сами серийные номера). Переустановка Windows его не меняет.
- Число устройств в лицензии — просто число, так что панель админа может вручную выдать лицензию на 20, 50 или 100 ПК.
- **Корпоративная версия отложена:** консоль для всех ПК, установка без участия пользователя, договоры и акты,
  поддержка с гарантированными сроками.

## 4. Запуск программы и лицензия

**Первый запуск:** заставка с обновлением → вход, регистрация или «Продолжить без входа» → выбор режима (существующий
экран приветствия) → главное окно.
**Следующие запуски:** заставка с обновлением → главное окно. Вход запоминается.

- Гость нажал на функцию Pro → окно «Это доступно в Pro» с кнопками «Войти» и «Купить». Войти можно и позже, через
  «Профиль».
- Pro работает **без интернета 14 дней** с последней успешной проверки лицензии. Потом нужна одна проверка через сеть.
  Отменённая подписка отключается после этого срока.
- Выход из аккаунта возвращает бесплатный режим, настройки остаются на компьютере.
- Отдельного экрана выбора устройства нет: телефон — пункт меню (раздел 5).

## 5. Меню и окно

Боковое меню — 6 разделов с вкладками внутри страницы (вкладки сверху, без выпадающих списков):

| В меню | Вкладки |
|---|---|
| Главная | — |
| Очистка | — |
| Компьютер | Комплектующие, Ускорение |
| Система | Процессы, Автозагрузка, Программы, Диски |
| Защита | Безопасность, Сеть, Проверка файлов |
| *разделитель* | |
| Телефон | Виден всегда; точка, когда iPhone подключён |
| *разделитель* | |
| Профиль и ⚙ (внизу) | Вход и подписка, «Написать нам»; настройки |

- Телефон отделён, потому что это работа с другим устройством. Без подключения страница показывает инструкцию:
  кабель, разблокировать, «Доверять этому компьютеру», где взять драйвер Apple. Позже сюда же — Android.
- Простой режим может прятать редкие вкладки, не трогая меню.
- Нижняя строка (`MainWindow.xaml`, строка 3): убрать « · Сделано для WaterCa7»; текст посередине (последняя запись
  журнала, обычно статус обновления) убирается, а статус обновления коротко встаёт рядом с версией в углу:
  `v1.3.0 · последняя версия`, `v1.3.0 · скачана 1.4.0`.
- **Комплектующие:** процессор, память, видеокарта, диски, материнская плата, батарея; состояние, износ SSD (SMART),
  износ батареи, температуры. Температуру процессора Windows без драйвера не отдаёт, а драйвер WinRing0 Защитник
  помечает как уязвимый — способ для процессора выбирается в спецификации этапа 2. Видеокарта, диски и батарея — без
  драйвера.
- **Проверка файлов:** перетаскивание в окно, кнопка «Выбрать файл» и пункт «Проверить в WaterCa7» в меню правой
  кнопки (ставит установщик). Окно работает с правами администратора, и Windows запрещает перетаскивание из обычного
  Проводника в такое окно — нужен обход через `ChangeWindowMessageFilterEx` и `WM_DROPFILES`. Проверка: Защитник,
  цифровая подпись, отметка «скачан из интернета». Свой антивирусный движок и драйвер ядра не делаем.

## 6. Установщик и права администратора

- Установщик на **Inno Setup** (русский язык, собирается в CI). Ставит программу в `Program Files`, создаёт ярлыки,
  запись в «Программах и компонентах», пункт в меню правой кнопки.
- При установке создаётся задача Планировщика «с наивысшими правами»; ярлыки запускают программу через неё — **без окна
  UAC**. `Program Files` обязателен: обычный пользователь не может подменить там exe, иначе задача стала бы дырой.
- Службы Windows нет. Расписание Pro — через Планировщик, наблюдение за «Загрузками» — через значок в трее.
- **Отдельный exe без установки больше не выпускается.**
- Автообновление: программа скачивает новый установщик, проверяет подпись (как сейчас `update.json`) и запускает его
  тихо. Пользователи 1.3 переходят на установщик при следующем обновлении; настройки (`%LOCALAPPDATA%`) сохраняются,
  старый exe установщик удаляет.
- Ожидается, что установка исправит и пропадающий значок (в `app.ico` все размеры 16–256 есть; вероятная причина —
  кэш значков Windows для exe, лежащего где попало). Пользователь уточнит, где именно значок пропадает.

## 7. Сервер

- Обычный хостинг **Beget, PHP и MySQL**. API — `waterca7.ru/api`, панель админа — `waterca7.ru/admin`; нового сайта
  в Beget не нужно (лимит 5 из 5). Supabase отклонён: серверы за рубежом, а данные россиян по 152-ФЗ хранятся в РФ.
- Что хранит: аккаунты (почта, хэш пароля), лицензии (тариф, срок, число устройств), привязанные ПК (хэш железа,
  дата привязки), оплаты, рефералы, обращения, анонимная статистика.
- Оплата — **ЮKassa** за одним адаптером, чтобы сменить сервис или форму (самозанятость → ИП) без изменений в программе.
- **Анонимная статистика:** случайный номер установки (без почты и железа) приходит вместе с проверкой обновлений.
  Выключатель «Отправлять анонимную статистику» в настройках, описание — в политике конфиденциальности.
- Проверка обновлений переезжает с GitHub на наш сервер.

## 8. Сайт, кабинет и панель админа

- **Сайт (вкладки):** Главная (одна кнопка «Скачать» по системе, скриншот, три возможности), Возможности (отметки
  «бесплатно» и «Pro»), Цены (Pro и Pro Семья, месяц / год / навсегда, таблица «бесплатно и Pro»), Поддержка (частые
  вопросы и форма), Войти → кабинет. Внизу: оферта, политика конфиденциальности, правила возврата, контакты — без них
  ЮKassa не подключит оплату.
- **Кабинет:** подписка (тариф, срок, продлить или отменить), мои компьютеры (отвязать), история оплат и чеки,
  реферальная ссылка.
- **«Написать нам»** в «Профиле» программы: текст и галочка «приложить сведения о системе и журнал». Обращения
  с сайта и из программы — в одном списке, ответ уходит на почту.
- **Панель админа:** статистика (установки, активные за день и месяц, версии, Windows или Mac, доход, продления и
  отмены); пользователи (поиск по почте, выдать подписку или покупку, корпоративные лицензии, сбросить ПК,
  заблокировать); обращения; цены и скидки.
- Страница на GitHub: после закрытия кода публичным лицом становится репозиторий с релизами — README со скриншотами
  (режим `--screenshots`), коротким описанием и ссылкой на сайт.

## 10. Открытые вопросы и риски

- **Автосписание подписок у самозанятых в ЮKassa** — уточнить до регистрации. Если его нет, лучше сразу ИП.
- **Подпись программы.** Для Windows сертификат выдаётся только на защищённом носителе (примерно 200–400 $ в год), и
  многие удостоверяющие центры не работают с резидентами РФ; Apple Developer Program — 99 $ в год, оплата из России
  затруднена. Нужно отдельное исследование в начале этапа 6; возможно, понадобится лицо за рубежом.
- **Иностранные покупатели.** SWIFT — это межбанковские переводы, а не приём карт. Paddle, Stripe и подобные с
  резидентами РФ, по имеющимся данным, не работают. Сначала только Россия; заграница — когда будет спрос.
- **152-ФЗ:** уведомить Роскомнадзор как оператор персональных данных, политика конфиденциальности, данные в РФ.
- Юридические и налоговые детали проверить у бухгалтера: условия меняются.

## 11. Не делаем

Свой антивирусный движок и драйвер ядра, VPN, обновление драйверов, чистку реестра, службу Windows, пробный период,
корпоративную версию (отложена), обязательную регистрацию.

## 12. Идеи у конкурентов (Касперский, Avast)

Берём (этап 5): обновление программ через winget, дубликаты, «кто подключён к Wi-Fi», проверка утечки почты и паролей,
надёжное затирание файлов, «усыпление» фоновых программ, модуль приватности Windows. Подробности — в
`docs/COMPETITORS.md`; его раздел «Наши принципы» обновляется вместе с этапом 4.

## 13. Продвижение (этап 6)

Каталоги (winget, Microsoft Store, softportal, comss, AlternativeTo); статьи на сайте под поисковые запросы; короткие
ролики «было/стало» (ВК, Rutube, YouTube, TikTok) и Telegram-канал; история создания на Хабре или Пикабу; реферальная
программа; технические блогеры и компьютерные мастерские.
