# Этап 1: установщик и запуск без UAC

Дата: 2026-10-23. Статус: решения приняты пользователем. Выпуск — версия 1.4.0. Первый этап общего плана развития.

## Решения пользователя

- Программа ставится установщиком Inno Setup в `Program Files`. Windows спрашивает права **один раз — при установке**;
  после этого ярлык открывает программу с правами администратора без окна UAC.
- Отдельный exe без установки **больше не выпускается**: 1.4.0 — только установщик. Моста для старых копий и
  автоматического переезда нет (скачиваний мало, все знакомые; пользователь сам попросит их переустановить). Копии 1.3.x
  при проверке обновлений тихо пишут «Не удалось обновиться» и продолжают работать.
- Установщик на русском или английском — по языку Windows. Ярлыки в «Пуске» и на рабочем столе (галочка включена),
  запись в «Программах и компонентах», в конце — галочка «Запустить программу».
- Удаление: файлы, ярлыки и задачи Планировщика. Настройки и журнал остаются, если не отметить «Удалить также настройки
  и журнал» (по умолчанию нет). Карантин — только после отдельного вопроса (по умолчанию нет).
- Стандартный пользователь (без прав администратора) запускает программу с паролем администратора, как сейчас: обходить
  UAC для него нельзя.

## 1. Что ставится

- Папка `C:\Program Files\WaterCa7s PC Cleaner` (`{autopf}`), установка для всех пользователей (`PrivilegesRequired=admin`).
- Программа в установщике — **обычная папка** самодостаточной сборки (`dotnet publish -r win-x64 --self-contained`,
  без single-file): запуск быстрее, не нужно распаковывать себя при каждом старте.
- Рядом с exe — файл-метка `WaterCa7sPcCleaner.installed` (его пишет только установщик). По нему программа узнаёт, что
  она установлена (раздел 3).
- `AppId` — постоянный GUID. Открытую программу установщик узнаёт по mutex `WaterCa7sPcCleaner.Instance` (имя из
  `SingleInstance`, проверка в `[Code]`): при ручной установке и при удалении просит её закрыть, при тихом обновлении ждёт.
- Файл установщика — `WaterCa7sPcCleaner-Setup.exe`. Скрипт — `installer/WaterCa7sPcCleaner.iss`; русские и английские
  тексты установщика — из стандартных `Russian.isl` / `Default.isl` плюс свои строки в `[CustomMessages]`.

## 2. Запуск без UAC

**Задача Планировщика** — по одной на пользователя: папка `\WaterCa7s PC Cleaner\`, имя `Start <SID>`.
Действие — `"<папка программы>\WaterCa7sPcCleaner.exe" --from-task`; принципал — SID пользователя,
`InteractiveToken`, `HighestAvailable`; запуск по требованию, без ограничения времени, не останавливать на батарее.
Регистрирует её **сама программа** (новый класс `Core/ElevatedTask.cs`, через `schtasks /create /xml`), чтобы вся
логика была в C# и под тестами:

- установщик в конце установки запускает `WaterCa7sPcCleaner.exe --register-task` (с правами установщика): задача
  создаётся для того, кто ставил, и программа выходит без окна;
- копия с правами, запущенная из `Program Files`, с включённым «Запускать с правами администратора», создаёт задачу для
  текущего пользователя, если её нет (второй администратор компьютера — один вопрос UAC, потом без вопросов);
- **задача создаётся только для exe внутри `%ProgramFiles%`** с меткой установки: папку обычный пользователь изменить
  не может. Задача на exe из «Загрузок» или `A:\` была бы дырой — любая программа подменила бы файл и получила права.

**Старт по ярлыку** (`App.OnStartup`, вместо нынешнего перезапуска через `runas` в `StartupElevation`):

1. Копия без прав занимает место (`SingleInstance`, как в 1.3.1).
2. Если «Запускать с правами администратора» включено, программа установлена и задача для этого пользователя есть —
   `AllowSetForegroundWindow(ASFW_ANY)`, `schtasks /run /tn "\WaterCa7s PC Cleaner\Start <SID>"`, выход.
3. Задача запустила копию с `--from-task`: она ждёт, пока предыдущая закроется (`--from-task` входит в
   `SingleInstance.WaitsForPrevious` и в `UpdateService.WithoutStartMarkers`). Если у неё всё-таки нет прав, она
   работает без них и не перезапускается по кругу (как с `--elevated-restart`).
4. Задачи нет или её не удалось запустить — прежний перезапуск через UAC (`StartupElevation.TryRelaunchElevated`).
   Без окна программа не остаётся никогда.

- Аргументы через задачу не передаются (её действие фиксировано): старт по ярлыку их и не имеет. Передача файла для
  «Проверить в WaterCa7» (этап 2) пойдёт через уже открытую копию, а не через задачу.
- Выключение «Запускать с правами администратора» в «Настройках» удаляет задачу текущего пользователя (если программа
  работает с правами; иначе задача просто не используется — ярлык смотрит на настройку раньше задачи).
- Удаление программы: `[UninstallRun]` — `WaterCa7sPcCleaner.exe --unregister-tasks` (вся папка задач), затем
  `schtasks /delete` как запасной путь.

## 3. Обновления

- Установленная копия: `UpdateEnvironment.IsInstalledBuild` = рядом с exe есть метка `WaterCa7sPcCleaner.installed`
  (сейчас — «single-file без dll рядом»; в папочной сборке dll лежат рядом всегда). Сборка для разработки по-прежнему не
  обновляется.
- `update.json`: файл для Windows — под ключом **`win-x64-setup`** (`WaterCa7sPcCleaner-Setup.exe`, адрес на релиз
  этой версии, размер, SHA-256), подпись прежняя. Ключа `win-x64` больше нет — поэтому 1.3.x и не обновляются.
  `UpdateManifest.Parse` читает `win-x64-setup`; `tools/make-update-manifest.ps1` получает `-Setup` вместо `-Exe`.
- Скачивание и проверка — как сейчас (`UpdateStore`, «установится при следующем запуске», заставка, кнопка в полоске).
- **Установка обновления** (`UpdateInstaller` для установщика):
  1. Копия работает с правами: проверенные байты (тот же приём «открыт с запретом записи, копируются ровно те байты,
     что посчитаны») копируются в `<папка программы>\Updates\` — туда может писать только администратор, так что файл
     нельзя подменить между проверкой и запуском.
  2. Запуск: `WaterCa7sPcCleaner-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /UPDATEDFROM=<версия>` и выход
     программы.
  3. Установщик ждёт, пока место программы освободится (до 30 с, `[Code]`, по тому же mutex), ставит файлы, задачу и
     запускает `WaterCa7sPcCleaner.exe --updated-from <версия>` — новая версия убирает за собой папку `Updates`.
  4. Копия без прав сама установщик не запускает (запуск из папки пользователя с правами администратора можно
     подменить): полоска обновления предлагает «Перезапустить с правами и установить» — обычный перезапуск через UAC,
     дальше как в п. 1.
- Две неудачные установки одной версии → «Скачайте её со страницы релизов», как сейчас.

## 4. Удаление

- `[UninstallDelete]` — папка программы целиком (включая `Updates`).
- `[Code]` `CurUninstallStepChanged`: вопрос «Удалить также настройки и журнал?» (по умолчанию «Нет»); если в
  карантине есть файлы — отдельный вопрос с их числом (по умолчанию «Нет»). Данные — в `%LOCALAPPDATA%\WaterCa7sPcCleaner`
  того, кто удаляет. При тихом удалении (`/VERYSILENT`) вопросы не задаются и всё остаётся.

## 5. Сборка, проверка, выпуск

- **CI** (`ci.yml`): папочная публикация → `ISCC installer/WaterCa7sPcCleaner.iss` (Inno Setup 6.7.3: установленный на
  раннере или `choco install innosetup --version 6.7.3`) → артефакт `WaterCa7sPcCleaner-Setup`.
- **Проверка установщика на раннере** (`tools/test-installer.ps1`, тот же job): тихая установка → файлы, метка, запись в
  «Программах и компонентах», ярлыки, задача Планировщика → установленная программа в режиме `--screenshots` (код 0, есть
  картинки) → установка поверх (как обновление) → тихое удаление → папки программы и задач нет, настройки остались.
  Раннер работает с правами администратора без UAC, поэтому старт по ярлыку **без** прав там не проверить — это шаг
  пользователя.
- **Выпуск** (`release.yml`): то же, плюс подпись `update.json` и релиз с файлами `WaterCa7sPcCleaner-Setup.exe`,
  `update.json`, `update.json.sig` (exe больше не прикладывается).
- **Локально** установщик собирается здесь же (`C:\Program Files (x86)\Inno Setup 6\ISCC.exe`), но **не запускается**:
  установка меняет систему. Проверку на этом компьютере делает пользователь (раздел 6).
- Документы: раздел «Установка» в README, `docs/ARCHITECTURE.md`, `docs/release-notes/1.4.0.md`.
- После выпуска — ссылка «Скачать» на waterca7.ru → `releases/latest/download/WaterCa7sPcCleaner-Setup.exe`
  (файловый менеджер Beget в Chrome пользователя, как раньше).

## 6. Проверка у пользователя (перед выпуском)

1. Установить сборку из CI; после установки программа открывается сама.
2. Закрыть, открыть ярлыком с рабочего стола — **без окна UAC**, с правами (в «Настройках» — «администратор»).
3. Быстро дважды кликнуть по ярлыку — одно окно.
4. Обновление: поставить сборку с номером выше поверх (или через проверку обновлений на тестовом `update.json`).
5. Удалить через «Программы и компоненты»: вопросы о настройках и карантине, после удаления нет папки и задачи.
6. Удалить старый `WaterCa7sPcCleaner.exe` из «Загрузок».

## 7. Риски, которые проверяются по ходу

- Права на задачу: копия без прав должна иметь право запустить свою задачу, созданную копией с правами (это обычная
  практика, но проверяется на шаге 6.2).
- Временная папка установщика при тихом обновлении: Inno распаковывает себя во временную папку — проверить, что версия
  6.7.3 делает её недоступной для обычного пользователя при запуске с правами.
- Программа на переднем плане после запуска из задачи: процесс стартует от службы Планировщика; `AllowSetForegroundWindow`
  из копии по ярлыку должен это решить.

## Не входит

Подпись установщика сертификатом (этап 6), пункт «Проверить в WaterCa7» в меню правой кнопки (этап 2), служба Windows,
переносная версия, автоматический переезд со старых exe.
