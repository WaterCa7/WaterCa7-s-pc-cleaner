# План развития

## v0.1 — консольная версия (Python, папка `cli-python`)
- [x] Процессы: топ CPU/RAM, эвристики подозрительных (подделки системных имён, запуск из Temp, двойные расширения, майнеры, RAT)
- [x] Мусор: temp, кэши браузеров/Discord/шейдеров, Windows Update, дампы; крупные файлы; пустые папки; безопасная очистка с пробным запуском
- [x] Программы: список установленных, нежелательное ПО, автозагрузка (реестр, папки, планировщик), хвосты удалённых программ
- [x] Железо и BIOS: UEFI/Legacy, Secure Boot, TPM, VT-x, возраст BIOS, XMP, одноканальная память, HDD/SSD, здоровье дисков, драйвер GPU, температуры, батарея, электропитание
- [x] Защита: антивирус, Defender, брандмауэр, UAC, SMBv1, RDP, обновления
- [x] Сеть: адаптеры и их скорость, трафик, задержки, DNS, Wi-Fi, открытые порты, соединения процессов, hosts, прокси
- [x] HTML/JSON-отчёт с оценкой 0–100

## v1.0 — приложение для Windows с окнами (C# / WPF)
- [x] Графический интерфейс с кнопками «Очистить», «Отключить», «Завершить», «Исправить»
- [x] Сборка в один `.exe`, не требующий установки .NET
- [x] Проверка цифровой подписи (Authenticode, включая каталожные подписи Windows)
- [x] Службы Windows и задания планировщика в автозагрузке; отключение как в Диспетчере задач (обратимо)
- [x] Расширения браузеров (Chrome, Edge, Яндекс, Opera, Brave, Vivaldi, Firefox)
- [x] Перехваты запуска (IFEO, Winlogon), скрытый прокси, подмена hosts с удалением строк
- [x] Удаление программ штатным деинсталлятором, «битые» записи, приложения Microsoft Store
- [x] Анализ места на диске, самые большие файлы, старые установщики, TRIM, оптимизация дисков
- [x] Рекомендации по ускорению с применением и откатом (питание, игровой режим, Game Bar, визуальные эффекты)
- [x] Точка восстановления Windows перед изменениями, резервные копии реестра, карантин
- [x] Журнал всех действий
- [x] Раздел «Сеть»: адаптеры, задержки, DNS, Wi-Fi, открытые порты, соединения программ
- [x] Отчёт в HTML, сравнение «было → стало»
