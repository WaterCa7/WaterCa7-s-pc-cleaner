# Что умеют другие программы и что мы берём себе

Обзор популярных бесплатных и условно-бесплатных утилит. ✅ — уже есть в WaterCa7s PC Cleaner, 🔜 — в планах ([ROADMAP](ROADMAP.md)), ❌ — делать не будем.

| Программа | Ключевые функции | Что берём |
|---|---|---|
| **CCleaner** | Чистка временных файлов и браузеров, «чистка реестра», менеджер автозагрузки, Health Check, обновление программ, поиск дубликатов | ✅ чистка temp/кэшей, ✅ автозагрузка, ✅ оценка здоровья и исправление в один клик; 🔜 чистка истории/cookies браузеров, 🔜 проверка обновлений программ (через `winget upgrade`), 🔜 дубликаты; ❌ чистка реестра — не ускоряет систему и может её сломать |
| **BleachBit** (open source) | Сотни «чистильщиков» для программ, затирание файлов, работает и на Linux | ✅ пробный анализ перед очисткой, ✅ консольная версия работает и на Linux; 🔜 описания целей в отдельных файлах (как CleanerML), 🔜 безопасное затирание (shred) |
| **Sysinternals Autoruns** | Все места автозапуска: Run-ключи, службы, задачи, драйверы, расширения проводника | ✅ Run/RunOnce, папки автозагрузки, планировщик, службы, ✅ IFEO и Winlogon, ✅ расширения браузеров; 🔜 WMI-подписки, драйверы |
| **Process Explorer / System Informer** | Дерево процессов, проверка подписи, отправка хэша в VirusTotal | ✅ проверка цифровой подписи (Authenticode и каталоги Windows), ✅ эвристики подозрительных процессов, ✅ VirusTotal по хэшу, ✅ проверка Защитником, ✅ завершение процесса и дерева, ✅ карантин; 🔜 дерево родитель→потомок |
| **TCPView / GlassWire** | Соединения каждого процесса, история трафика, оповещения о новых приложениях в сети | ✅ соединения и открытые порты по процессам, ✅ подозрительные порты; 🔜 трафик по процессам, 🔜 режим наблюдения с историей |
| **WizTree / WinDirStat** | Карта занятого места на диске | ✅ разбивка по папкам, самые большие файлы, типы файлов, старые установщики |
| **CrystalDiskInfo** | SMART, температура и ресурс дисков | ✅ тип и состояние дисков, TRIM, температура и износ (с правами администратора); 🔜 полные SMART-атрибуты |
| **HWiNFO / CPU-Z / Speccy** | Подробное железо, датчики | ✅ CPU, RAM (частота, каналы, XMP), GPU, монитор, диски, BIOS/UEFI, батарея; 🔜 датчики через LibreHardwareMonitor |
| **O&O ShutUp10++ / W10Privacy** | Отключение телеметрии и рекламы Windows | 🔜 модуль приватности с откатом изменений |
| **Malwarebytes AdwCleaner** | Поиск рекламного ПО, тулбаров, угонщиков браузера | ✅ нежелательные программы, ✅ hosts и прокси, ✅ расширения браузеров; 🔜 проверка ярлыков браузеров и стартовых страниц |
| **Revo Uninstaller / Bulk Crap Uninstaller** | Удаление программ с «хвостами», массовое удаление | ✅ удаление штатным деинсталлятором, ✅ «битые» записи, ✅ приложения Microsoft Store; 🔜 чистка хвостов после удаления |
| **Wise Care / Advanced SystemCare** | «Ускорение одной кнопкой», игровой режим | ✅ советы по ускорению с применением и откатом (питание, игровой режим, Game Bar, HAGS, XMP, частота монитора); ❌ агрессивные «твики» без объяснений |

## Наши принципы (отличие от коммерческих «чистильщиков»)

1. **Бесплатно и открыто**, без рекламы и навязанных программ.
2. **Ничего не удаляется и не меняется без подтверждения**: перед изменениями реестра — резервная копия, перед системными изменениями — точка восстановления, подозрительные файлы — в карантин.
3. **Каждая находка объясняет «почему» и «что делать»**, а не пугает красными цифрами.
4. **Никакой «чистки реестра»** и сомнительных твиков.
5. **Работает без интернета**; в сеть ходит только проверка задержек в разделе «Сеть» и ссылки, которые вы открываете сами.
