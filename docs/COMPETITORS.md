# Что умеют другие программы и что мы берём себе

Обзор популярных бесплатных и условно-бесплатных утилит. ✅ — уже есть в PC Cleaner, 🔜 — в планах ([ROADMAP](ROADMAP.md)), ❌ — делать не будем.

| Программа | Ключевые функции | Что берём |
|---|---|---|
| **CCleaner** | Чистка временных файлов и браузеров, «чистка реестра», менеджер автозагрузки, Health Check, обновление программ, поиск дубликатов | ✅ чистка temp/кэшей, ✅ автозагрузка, ✅ оценка здоровья; 🔜 чистка истории/cookies браузеров, 🔜 проверка обновлений программ (через `winget upgrade`), 🔜 дубликаты; ❌ чистка реестра — не ускоряет систему и может её сломать |
| **BleachBit** (open source) | Сотни «чистильщиков» для программ, затирание файлов, работает и на Linux | ✅ кроссплатформенность, ✅ пробный запуск; 🔜 описания целей в отдельных файлах (как CleanerML), 🔜 безопасное затирание (shred) |
| **Sysinternals Autoruns** | Все места автозапуска: Run-ключи, службы, задачи, драйверы, расширения проводника | ✅ Run/RunOnce, папки автозагрузки, планировщик; 🔜 службы, WMI-подписки, расширения браузеров, IFEO |
| **Process Explorer / Process Hacker (System Informer)** | Дерево процессов, проверка подписи, отправка хэша в VirusTotal | ✅ эвристики подозрительных процессов, ✅ `pccleaner hash` + ссылка на VirusTotal, ✅ завершение процесса; 🔜 проверка цифровой подписи (Authenticode), 🔜 дерево родитель→потомок |
| **TCPView / GlassWire** | Соединения каждого процесса, история трафика, оповещения о новых приложениях в сети | ✅ соединения и порты по процессам, ✅ подозрительные порты; 🔜 трафик по процессам, 🔜 режим наблюдения с историей |
| **WizTree / WinDirStat** | Карта занятого места на диске | ✅ крупные файлы; 🔜 разбивка по папкам с визуализацией в отчёте |
| **CrystalDiskInfo** | SMART, температура и ресурс дисков | ✅ статус здоровья диска (Get-PhysicalDisk); 🔜 полные SMART-атрибуты (через smartctl), остаток ресурса SSD |
| **HWiNFO / CPU-Z / Speccy** | Подробное железо, датчики | ✅ CPU, RAM (частота, каналы, XMP), GPU, диски, BIOS, батарея; 🔜 датчики через LibreHardwareMonitor |
| **O&O ShutUp10++ / W10Privacy** | Отключение телеметрии и рекламы Windows | 🔜 модуль приватности с откатом изменений |
| **Malwarebytes AdwCleaner** | Поиск рекламного ПО, тулбаров, угонщиков браузера | ✅ список нежелательных программ, ✅ проверка hosts и прокси; 🔜 проверка ярлыков браузеров и стартовых страниц |
| **Revo Uninstaller / Bulk Crap Uninstaller** | Удаление программ с «хвостами», массовое удаление | ✅ поиск остатков удалённых программ; 🔜 удаление из интерфейса + чистка хвостов |
| **Wise Care / Advanced SystemCare** | «Ускорение одной кнопкой», игровой режим | ✅ советы по оптимизации (питание, игровой режим, HAGS, XMP); ❌ агрессивные «твики» без объяснений |

## Наши принципы (отличие от коммерческих «чистильщиков»)

1. **Бесплатно и открыто**, без рекламы и навязанных программ.
2. **Ничего не удаляется без явного `--apply`** и подтверждения. По умолчанию — только отчёт.
3. **Каждая находка объясняет «почему» и «что делать»**, а не пугает красными цифрами.
4. **Никакой «чистки реестра»** и сомнительных твиков.
5. **Работает без интернета**; в сеть ходит только тест задержек (отключается `--offline`).
