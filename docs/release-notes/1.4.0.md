## Что нового в 1.4.0

- **Программа теперь устанавливается.** Скачайте `WaterCa7sPcCleaner-Setup.exe`: программа встанет в «Program Files», появится в «Пуске» и в «Программах и компонентах», а на рабочем столе — если оставить галочку.
- **Без вопросов Windows при запуске** на учётной записи администратора. Разрешение спрашивается один раз — при установке. Дальше ярлык открывает программу сразу с правами. На обычной учётной записи Windows по-прежнему спрашивает пароль администратора.
- **Быстрее запускается**: программе больше не нужно распаковывать себя при каждом старте.
- **Обновления ставятся установщиком**: без вопросов, видно только окно с ходом установки, программа сама перезапускается в новой версии. Если установка не удалась, открывается прежняя версия.
- **Если у вас была версия 1.3 или старше** (один файл `WaterCa7sPcCleaner.exe`): скачайте установщик с сайта, установите программу и удалите старый файл. Настройки, журнал и карантин сохранятся.
