## Что нового в 1.5.0

- **Новое меню.** Разделы собраны по смыслу: «Главная», «Очистка», «Компьютер» (комплектующие и ускорение), «Система» (процессы, автозагрузка, программы, диски) и «Защита» (безопасность и сеть). Внутри раздела — вкладки, внизу — «Профиль» и «Настройки». В простом режиме лишние вкладки спрятаны.
- **Аккаунт WaterCa7.** Войти можно прямо в программе: по почте и паролю, через браузер или зарегистрироваться с кодом из письма; забытый пароль восстанавливается там же. Входить не обязательно — без аккаунта программа работает как раньше.
- **Профиль.** Тариф и срок подписки, список компьютеров с отвязкой, промокод и «Написать нам» — обращение в поддержку прямо из программы, при желании с журналом программы.
- **Если все места для компьютеров заняты**, при входе программа покажет список и предложит отвязать один из них.
