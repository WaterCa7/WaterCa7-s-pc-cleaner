## Что нового в 1.2.0

- **Кнопки «Исправить» на Главной.** У большинства найденных проблем теперь есть кнопка, которая решает её одним нажатием: очистить системный мусор, отключить подозрительную запись автозагрузки, убрать подмену в файле hosts, выключить прокси, сбросить кэш DNS, перезагрузить компьютер и другое. Где исправить может только сама Windows, появилась кнопка «Открыть настройки».
- **«Исправить всё».** Одна кнопка исправляет всё, что можно безопасно исправить разом, — с одним подтверждением и точкой восстановления. Удаление программ, очистка Корзины и перезагрузка запускаются только отдельно.
- **Галочки в Процессах, Автозагрузке и Программах.** Отметьте несколько пунктов и завершите, отключите, включите или удалите их одной кнопкой. Несколько программ удаляются по очереди, а где программа это умеет — тихо, без окон.
- **Экран загрузки.** При запуске программа проверяет, нет ли новой версии; если есть — скачивает её и сразу перезапускается уже обновлённой. Кнопка «Пропустить» откроет программу сразу, а обновление поставится в следующий раз.
- **Права администратора сразу.** Программа запускается с правами администратора, поэтому все проверки и исправления доступны сразу (Windows спросит разрешение). Если ответить «Нет», программа откроется в ограниченном режиме. Выключить — «Настройки → Основные».
- **Удалённые браузеры больше не показываются.** Opera и Firefox после удаления оставляют папки профилей; программа больше не принимает их за установленные браузеры и не предупреждает об их старых расширениях.
- **Понятнее ошибки** у пользователей с русским именем учётной записи Windows: сообщения о недоступных файлах теперь всегда на русском.
