# WaterCa7s PC Cleaner

Программа для Windows 10/11, которая чистит компьютер от мусора, показывает, что его нагружает, находит подозрительные программы и подсказывает, как его ускорить. Ничего не удаляется и не меняется без вашего подтверждения.

Сайт: https://waterca7.ru

## Скачать

- **Windows:** `WaterCa7sPcCleaner-Setup.exe` на странице [Releases](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner/releases/latest).
- **Mac:** отдельный репозиторий [WaterCa7-s-pc-cleaner-mac](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner-mac/releases/latest).
- **Linux:** версия для командной строки в папке [cli-python](cli-python).

Программа обновляется сама: новая версия скачивается отсюда и проверяется по цифровой подписи. Если Windows предупредит о неизвестном издателе, нажмите «Подробнее» → «Выполнить в любом случае».

## Что в этом репозитории

Здесь лежат выпуски программы и версия для командной строки. Исходный код программы для Windows начиная с версии 1.6.0 закрыт.

Сообщить об ошибке можно в разделе [Issues](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner/issues).

# WaterCa7s PC Cleaner (English)

A Windows 10/11 app that removes junk, shows what is slowing the computer down, finds suspicious programs and suggests how to speed it up. Nothing is deleted or changed without your confirmation.

Download the installer from [Releases](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner/releases/latest). This repository holds the releases and the command-line version ([cli-python](cli-python)). The source code of the Windows app is closed starting with version 1.6.0.
