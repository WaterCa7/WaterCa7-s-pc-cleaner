# WaterCa7s PC Cleaner

Бесплатная программа для Windows 10/11, которая чистит компьютер от мусора, показывает, что работает в фоне,
находит подозрительные и нежелательные программы и подсказывает, как ускорить железо и Windows.

Всё объясняется простым языком, и **ничего не удаляется и не меняется без вашего подтверждения**.

## Что умеет

| Раздел | Что делает |
|---|---|
| **Главная** | Оценка состояния ПК от 0 до 100, проверка всего компьютера в один клик, живые показатели процессора, памяти и диска, исправление найденного одной кнопкой |
| **Очистка** | Временные файлы Windows и программ, кэш браузеров (Chrome, Edge, Яндекс, Opera, Brave, Vivaldi, Firefox — только кэш, пароли и история не трогаются), кэш шейдеров видеокарты, Discord, Steam, кэш обновлений Windows, отчёты об ошибках, дампы, корзина, очистка компонентов Windows (DISM) |
| **Процессы** | Что сейчас нагружает процессор и память, проверка цифровой подписи каждого процесса, поиск подделок под системные процессы, майнеров и программ удалённого доступа; завершение, проверка Защитником Windows и VirusTotal, карантин |
| **Автозагрузка** | Реестр, папки автозагрузки, планировщик заданий и службы; отключение так же, как в Диспетчере задач (обратимо), поиск «битых» записей |
| **Программы** | Установленные программы и приложения Microsoft Store, нежелательный софт (Амиго, Guard@Mail.ru, «ускорители» и т. п.), предустановленный мусор Windows, удаление штатным деинсталлятором |
| **Диски** | Свободное место, тип и здоровье накопителей (SSD/HDD/NVMe), что занимает место, самые большие файлы, старые установщики в «Загрузках», TRIM, оптимизация диска |
| **Ускорение** | Характеристики ПК и конкретные советы: включён ли XMP у памяти, одноканальная память, частота монитора, SSD, схема питания, игровой режим, запись Xbox Game Bar, аппаратное планирование GPU, драйверы, BIOS. Безопасные настройки применяются одной кнопкой и так же откатываются |
| **Сеть** | Скорость адаптеров, задержки до интернета, DNS, сигнал Wi-Fi, открытые порты и соединения программ |
| **Безопасность** | Защитник Windows и другие антивирусы, брандмауэр, UAC, подмена файла hosts, перехват запуска программ (IFEO, Winlogon), скрытый прокси, DNS, обновления Windows, расширения браузеров |
| **Настройки** | Исключения очистки, доверенные программы, журнал всех действий, резервные копии реестра, карантин, точки восстановления |

## Безопасность

- Перед каждым изменением — окно с подтверждением, где написано, что именно будет сделано.
- Перед изменением реестра сохраняется резервная копия (`.reg`), её можно восстановить в «Настройках».
- Перед пакетом системных изменений создаётся точка восстановления Windows (если программа запущена от администратора).
- Подозрительные файлы перемещаются в карантин, а не удаляются. Из карантина их можно вернуть.
- Очистка удаляет только временные файлы и кэш, не заходит по символическим ссылкам и junction-папкам,
  не трогает файлы моложе 24 часов и занятые файлы.
- Программы удаляются только их собственным деинсталлятором. Системные процессы Windows завершить нельзя.
- Никакой «чистки реестра» и сомнительных твиков: каждая рекомендация объясняет, зачем она нужна.
- Все действия записываются в журнал (`%LOCALAPPDATA%\WaterCa7sPcCleaner\Logs`).

## Установка

1. Откройте вкладку **Actions** репозитория → последнюю успешную сборку **CI** → в разделе **Artifacts**
   скачайте `WaterCa7sPcCleaner-win-x64` (архив с одним файлом `WaterCa7sPcCleaner.exe`, около 64 МБ).
   Когда появятся релизы, файл можно будет скачать и со страницы
   [Releases](https://github.com/WaterCa7/WaterCa7-s-pc-cleaner/releases).
2. Распакуйте и запустите. Для полного доступа (системные папки, службы, HKLM) нажмите в программе
   «Запустить как админ» или запустите файл правой кнопкой мыши → «Запуск от имени администратора».

Собранный `.exe` не требует установки .NET. Windows может предупредить, что файл от неизвестного издателя
(он не подписан сертификатом) — нажмите «Подробнее» → «Выполнить в любом случае».
Если вы собираете проект сами, нужен [.NET SDK 7 или новее](https://dotnet.microsoft.com/download/dotnet).

## Сборка из исходников

```bash
dotnet build WaterCa7sPcCleaner.sln -c Release
dotnet test WaterCa7sPcCleaner.sln -c Release
dotnet publish src/PcCleaner/PcCleaner.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Режим самопроверки без изменений в системе (делает скриншоты всех страниц):

```bash
WaterCa7sPcCleaner.exe --screenshots screenshots
```

Устройство проекта описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
