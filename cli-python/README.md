# WaterCa7 PC Cleaner — консольная версия (Python)

> Это консольная версия с HTML-отчётом. Основное приложение с окнами (C#/WPF) описано в [README в корне репозитория](../README.md).

Бесплатная программа, которая проверяет компьютер и подсказывает, как сделать его быстрее и безопаснее.

Что она делает:

- **Процессы**: показывает, что нагружает процессор и память, и находит подозрительные процессы: подделки под системные (`svch0st.exe`), запуск из Temp, двойные расширения (`счёт.pdf.exe`), майнеры, программы удалённого доступа.
- **Мусор**: временные файлы, кэши браузеров, Discord и шейдеров, кэш Windows Update, дампы падений, корзина, крупные файлы, пустые папки.
- **Программы**: список установленных программ, нежелательный софт (Amigo, Mail.ru, «ускорители» и т. п.), автозагрузка (реестр, папки, планировщик задач), остатки удалённых программ.
- **Железо и BIOS**: UEFI или Legacy, Secure Boot, TPM, виртуализация, возраст BIOS, включён ли XMP/EXPO, одноканальная память, HDD или SSD, здоровье дисков, драйвер видеокарты, температуры, износ батареи, схема электропитания, быстрый запуск, игровой режим, HAGS.
- **Защита**: антивирус, Defender, брандмауэр, UAC, SMBv1, RDP, давность обновлений.
- **Сеть**: адаптеры и их скорость (например, кабель на 100 Мбит), текущий трафик, задержка до интернета, скорость DNS, сигнал Wi-Fi, открытые порты, соединения каждого процесса, подозрительные порты (бэкдоры, майнинг-пулы), подмена файла `hosts`, скрытый прокси.
- **Отчёт**: оценка от 0 до 100, отчёт в HTML и JSON, у каждой находки есть объяснение и рекомендация.

Программа **ничего не удаляет и не меняет без вашей команды**.

## Установка (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) и при установке отметьте «Add Python to PATH».
2. Скачайте проект: зелёная кнопка **Code → Download ZIP** и распакуйте архив.
3. Откройте папку `cli-python` и дважды щёлкните `run.bat`. Для полной проверки (соединения, TPM, службы) запустите его правой кнопкой мыши → «Запуск от имени администратора».

Отчёт откроется в браузере.

## Командная строка

```bash
pip install -r requirements.txt

python -m pccleaner scan --open          # полная проверка, отчёт в браузере
python -m pccleaner scan --only network  # только сеть (processes,junk,apps,hardware,security,network)
python -m pccleaner scan --quick --offline --json report.json

python -m pccleaner targets              # что умеет чистить
python -m pccleaner clean                # пробный запуск: сколько освободится
python -m pccleaner clean --apply        # удалить (спросит подтверждение)
python -m pccleaner clean --targets user_temp,chrome_cache --apply

python -m pccleaner hash C:\путь\к\file.exe   # SHA-256 и ссылка на VirusTotal
python -m pccleaner kill 1234                 # завершить процесс (системные защищены)
```

## Безопасность очистки

- Удаляются только файлы старше 24 часов (меняется через `--min-age`), чтобы не трогать то, что сейчас используется.
- Чистятся только временные папки и кэши. Корзину, «Загрузки» и журналы программа только показывает, их разбираете вы сами.
- Символические ссылки не обходятся, поэтому файлы за пределами папки с мусором не пострадают.
- Файлы, занятые программами, пропускаются.

## Разработка

```bash
pip install -r requirements.txt pytest
python -m pytest
```

Структура: `pccleaner/modules/*.py` — модули проверки, `report.py` — отчёты, `advisor.py` — оценка и советы, `cli.py` — команды.
Сравнение с CCleaner, BleachBit, Autoruns и другими программами — в [docs/COMPETITORS.md](../docs/COMPETITORS.md), план развития — в [docs/ROADMAP.md](../docs/ROADMAP.md).

Поддерживаются Windows 10/11 (основная платформа) и Linux. На macOS работает базовая часть.
